# MiniRangeFader

Very simple addon that allows you to customise the transparency value for units out of range.

Since Midnight the out of range alpha transparency has changed from 0.55 to 0.3 which is far more aggressive and not many people like this. Using this addon you can restore it back to 0.55 or whatever value you prefer.
